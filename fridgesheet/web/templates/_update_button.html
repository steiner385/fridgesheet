{# The update button, and the reasons it is sometimes absent. A button that downloads and executes an installer is not offered when we can already predict it would strand the household -- see the spec's section 6. The reason, when there is one, is a plain line of text rather than a tooltip on a disabled control: this page is read on phones and on a kitchen kiosk, both places nothing hovers, so a tooltip is a tooltip nobody ever sees. It is rendered in the Updates card (settings.html), beside the PIN field it is usually about, not here below it (#145). The `#update-action` wrapper is always rendered, even empty, so that "Check for updates now" (`_update_check.html`) has somewhere to swap this block out of band when a check finds a release. The poll that follows a successful update lives in settings.html, not here: a script inside a block that can be swapped in more than once would register its listener once per swap. #}
