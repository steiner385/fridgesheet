# Kid Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A browser remembers who is looking, from one tap on a chooser; a kid's device opens on their plan with a rail that names only their pages, and the grown-up view stays one tap away.

**Architecture:** One cookie, `fridgesheet_who`, read once per request into `page_context` as `who` and `who_student`. `base.html` draws a kid rail when `who_student` is set; `/` goes by the cookie; Trends and Changes fall back to the cookie's kid when no `kid` parameter is given. No login, no new tables.

**Tech Stack:** Python 3.12, FastAPI, Jinja2, pytest. Run tests with `env -u PYTHONPATH <venv>/bin/python -m pytest`.

**Spec:** `docs/superpowers/specs/2026-09-27-plan-fills-itself-design.md`, section 13 (and §11 for the phrase keys, §14 for what is out of scope). Depends on `2026-09-27-plan-fills-itself.md` being merged first (the kid's home is the plan with Must finish, and the stale banner links to `#must-finish`).

## Global Constraints

- No login, no PIN, no page hidden from anyone who types its address (spec §13.1, §14). The chooser removes distraction, not access.
- Every page still renders with an empty database and with a populated one (`browser-app` success metric).
- Every child sees every row and every action on every tier and in both modes (`tests/test_web_tier_parity.py`).
- New words are `phrasing.PHRASES` keys in three tiers: `copy.who_looking`, `copy.who_remember`, `copy.a_grownup`, `copy.not_name` (`{name}`), `copy.switch_to_kid`.
- The cookie is `fridgesheet_who`, value a student key or `family`, one year, `path=/`, `SameSite=Lax`, `HttpOnly`, no `Secure` (plain http on the LAN).
- Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. **A cookie naming a kid who was later hidden or renamed:** `/` must show the chooser and clear the cookie, never 404 or loop. Pinned in Task 1.
2. **An htmx answer swap on a kid-mode page:** `_after_answer.html` targets `qcount-all` and `q-head`, which the kid rail does not draw; the swap must be dropped silently, not error. Pinned in Task 2.
3. **A kid-mode reader on a sibling's page by address:** the page renders (no access rule), the rail is still the reader's own, and the body tier is the page's student's. Pinned in Task 2.
4. **Trends with `?kid=` for a sibling while in kid mode:** the parameter wins, the picker is still hidden. Pinned in Task 3.
5. **A student key with characters that need URL-encoding (a space, an apostrophe):** the rail links, the chooser form and the `/` redirect must all encode it. Pinned in Task 1 and Task 2.

In `fridgesheet/web/app.py`, above `page_context`:

```python
WHO_COOKIE = "fridgesheet_who"
FAMILY = "family"
WHO_MAX_AGE = 365 * 24 * 3600


def who_of(request: Request, conn: sqlite3.Connection) -> tuple[str | None, sqlite3.Row | None]:
    """Who this browser said is looking (spec 2026-09-27 §13.1): ("family", None) for a
    grown-up, (key, row) for a visible student, (None, None) when nobody has chosen or the
    cookie names a kid who is hidden or gone. Not a login: a cookie anyone can set."""
    raw = request.cookies.get(WHO_COOKIE)
    if not raw:
        return None, None
    if raw == FAMILY:
        return FAMILY, None
    s = students.by_key(conn, raw)
    if s is None or s["hidden"]:
        return None, None
    return raw, s


def remember_who(response, who: str):
    response.set_cookie(WHO_COOKIE, who, max_age=WHO_MAX_AGE, path="/", samesite="lax", httponly=True)
    return response


def forget_who(response):
    response.delete_cookie(WHO_COOKIE, path="/")
    return response
```

```python
"""Who is looking (spec 2026-09-27 §13.1): one tap, remembered by the browser, changed by
one tap. Not a login -- the household network is the boundary, as it is everywhere else."""
from __future__ import annotations

import sqlite3

from fastapi import APIRouter, Form, HTTPException, Request
from fastapi.responses import RedirectResponse

from ..app import Db, FAMILY, remember_who, render
from ..stores import students

router = APIRouter()


@router.get("/who")
def chooser(request: Request, conn: sqlite3.Connection = Db):
    return render(request, conn, "who.html", kids=students.visible(conn))


@router.post("/who")
def choose(request: Request, who: str = Form(...), conn: sqlite3.Connection = Db):
    if who != FAMILY:
        s = students.by_key(conn, who)
        if s is None or s["hidden"]:
            raise HTTPException(404, "no such kid")
    return remember_who(RedirectResponse("/", status_code=303), who)
```
