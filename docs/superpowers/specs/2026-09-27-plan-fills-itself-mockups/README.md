# Mockups for the 2026-09-27 "plan fills itself" spec

Throwaway, not product code. Each `.html` links the app's real `app.css`; the small
`<style>` block at the top of each file is what the real change would add. `shoot.py`
renders every page at 1440×900 and at 390×844 (2×, touch) with Playwright.

| File | What it shows |
|---|---|
| `plan-kid.html` | Doug's plan in kid mode (older tier): the kid rail, Must finish in its sections, a step the school has, Asked the school, Worth checking open on a graded-since-asked item |
| `who.html` | The chooser at `/who` |
| `today-parent.html` | The grown-up Today page with one headline per kid and "Switch to a kid's view" |

The sample data is invented.
